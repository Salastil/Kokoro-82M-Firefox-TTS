Kokoro Reader

Reads articles and selected text aloud using Kokoro-82M, synthesized by a small companion server running on your own machine (see server/ in the repo for setup) -- not a cloud API. No text or audio leaves your network.

Companion server

Paste the URL and auth token the server printed when it first started (also in its config file, and in journalctl --user -u kokoro-reader-server if you installed it as a systemd service).

Voice & speed

Advanced

Text is split into sentence-sized pieces and sent to the server one at a time so playback can start before the whole thing is synthesized. Smaller values start playing sooner per piece; larger values usually sound more natural and mean fewer requests.
